# CLAUDE.md

Guidance for Claude Code in this repository. See `README.md` for features, setup and configuration.

## Rules

- **Changelog on every commit.** Each commit adds its changes to `CHANGELOG.md` in the same commit: a bullet at the top
  of the section for today's date (`## YYYY-MM-DD`, create it above the previous dates if missing). Write in English,
  describe what changed for users or developers, not the files touched. Several related changes can share a bullet
  with sub-bullets.
- **User changelog alongside.** Whenever a commit adds something users notice to `CHANGELOG.md` (new feature,
  fix), it also adds a short, non-technical entry to `apps/web/src/changelog.ts` (the "What's new" page under
  Account): at the top of today's day (create it if missing), `kind` `new` or `fix`, text in German and English
  (`de`/`en`), no file names, endpoints or migrations. Developer-only changes (refactors, tests, docs, CI) get none.
- **Sync is copy and paste only.** pr0game's rules forbid automation: never add code that runs on game pages
  (userscripts, bookmarklets, extensions) or endpoints meant for automated submission. Improvements to syncing stay
  inside the hub (paste, clipboard, file upload).
- **No deployment details.** Server setup, hosts and SSH belong to the private deployment repository. This repository
  only builds the Docker image and sends the `repository_dispatch` from CI.
- **Language.** Code, comments, commit messages, README and changelog in English. UI texts live in
  `apps/web/src/locales/de.ts` and `en.ts`; always update both. Texts of push notifications are built by the server and
  live in `apps/server/src/push.ts` (German and English; English is typed against German, so a missing text fails the
  typecheck).
- **OpenAPI with API changes.** The public contract is [`apps/server/openapi.yaml`](apps/server/openapi.yaml)
  (served as `/api/openapi.json` and `.yaml`). Any commit that adds, removes or changes HTTP API behavior—paths,
  methods, auth, query/header parameters, or response shape—must update that file in the same commit so it stays
  accurate (paths, `operationId`s, security, and schemas for affected operations; descriptions in English).
- **Personal rules** of a contributor go into `CLAUDE.local.md` (gitignored, loaded in addition to this file).

## Commands

```bash
pnpm install
pnpm --filter "./packages/*" build   # web and server import the built packages
pnpm typecheck
pnpm test
pnpm build
```

## Layout

- `packages/parser` (`@pr0hub/core`): page parsers (cheerio), element data in `src/data/` (generated by `pnpm gen:tech` / `pnpm gen:costs`).
- `packages/flight` (`@pr0hub/flight`): flight math ported from the game's `FleetFunctions` (distance, ship speed,
  duration, consumption, recall), ACS planning (`acs.ts`), retime candidates (`retime.ts`) and interplanetary
  missiles (`missile.ts`: range, flight time, `calculateMIPAttack`); must stay second-exact with the game and the
  flight calculator.
- `packages/loot` (`@pr0hub/loot`): ACS loot settlement (loot shares like the game's `calculateSteal`, covering
  costs, profit split, transfers), used by the loot calculator in `apps/tools` and by the hub.
- `apps/server`: Fastify + SQLite; migrations in `migrations/` (numbered SQL files); every game-data query goes through `groupContext` so data stays within its group; OpenAPI spec in `openapi.yaml`.
- `apps/tools`: static tools (Vite, no framework): `index.html`, `flight-calculator/` (UI in `main.js`, calculation
  in `src/core.ts` on top of `@pr0hub/flight`), `acs-loot/` (glue in `src/loot.ts` on top of `@pr0hub/loot`) and
  `ipm-calculator/` (glue in `src/missile.ts` on top of `@pr0hub/flight`); each tool has its UI in `main.js` and its
  texts DE/EN in `i18n.js`. All pages share `shared/tools.css` and `shared/shell.js` (header with language switch
  and share link, texts via `data-t*`, toast, tooltips); Docker target `tools`.
- `apps/web`: Vue 3 SPA; the mobile layout starts below 800 px (`useMobile` in `composables.ts`, same breakpoint in `style.css`).
