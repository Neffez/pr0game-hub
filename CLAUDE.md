# CLAUDE.md

Guidance for Claude Code in this repository. See `README.md` for features, setup and configuration.

## Rules

- **Changelog on every commit.** Each commit adds its changes to `CHANGELOG.md` in the same commit: a bullet at the top
  of the section for today's date (`## YYYY-MM-DD`, create it above the previous dates if missing). Write in English,
  describe what changed for users or developers, not the files touched. Several related changes can share a bullet
  with sub-bullets.
- **Sync is copy and paste only.** pr0game's rules forbid automation: never add code that runs on game pages
  (userscripts, bookmarklets, extensions) or endpoints meant for automated submission. Improvements to syncing stay
  inside the hub (paste, clipboard, file upload).
- **No deployment details.** Server setup, hosts and SSH belong to the private deployment repository. This repository
  only builds the Docker image and sends the `repository_dispatch` from CI.
- **Language.** Code, comments, commit messages, README and changelog in English. UI texts live in
  `apps/web/src/locales/de.ts` and `en.ts`; always update both.
- **Personal rules** of a contributor go into `CLAUDE.local.md` (gitignored, loaded in addition to this file).

## Commands

```bash
pnpm install
pnpm --filter @pr0hub/core build   # web and server import the built parser package
pnpm typecheck
pnpm test
pnpm build
```

## Layout

- `packages/parser` (`@pr0hub/core`): page parsers (cheerio), element data in `src/data/` (generated by `pnpm gen:tech` / `pnpm gen:costs`).
- `apps/server`: Fastify + SQLite; migrations in `migrations/` (numbered SQL files); every game-data query goes through `groupContext` so data stays within its group.
- `apps/web`: Vue 3 SPA; the mobile layout starts below 800 px (`useMobile` in `composables.ts`, same breakpoint in `style.css`).
